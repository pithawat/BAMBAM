# CR-002 — Plan-owned locations, asset types and a simpler settings layout

Status: APPROVED (2026-10-26) — applied to the source docs with CR-001 on 2026-10-26 (D-111). Owner explicitly requested these revisions; the design was approved 2026-10-26.
Requested: 2026-10-26 by owner
Size: M

## What changes

- Add equipment types (`asset_type`) and make them immediately selectable when adding equipment. Admin and Superadmin can manage this master data.
- Remove both top strips entirely, including breadcrumbs, notification bell and account avatar. Remove the logo and CPAC office block.
- Floors and rooms come from the building plan; settings must not create them. Allow renaming an existing building or room. Remove the prototype's building/first-floor creation workflow and floor-name editing.
- Clarify visual hierarchy: one page heading, one main working area, subdued navigation/context and a clearly placed primary action.

## Preparation notes

- Final asset-type code-prefix/mount/3D representation and API validation are preparation concerns. The prototype uses the selected list icon, with a generic equipment icon by default.
- Product access, persistence and concurrency checks remain outside this standalone visual prototype.
