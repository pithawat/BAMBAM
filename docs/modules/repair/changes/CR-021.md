   - Placed **between `ห้องหรือจุดที่เกิด` and `บอกจุดเพิ่มเติม`** (now under the spot field).
   - Card frame: info icon + heading (CR-020 copy) + sub-line on the left, a count badge `พบ {n} งาน` on the right.
   - Each case is one **horizontal row**: report photo on the left (or the category icon tile), ticket no / title / location / status badge in the middle, the action button on the right (desktop and tablet).    - The CR-020 hint moves to a note **at the bottom of the card**.
   - The submit-time S04 sheet / dialog uses the same case rows.
2. **Duplicate blocks at the location step (behaviour, BR-F03-2):** while #22 returns a case with `blocksReport: true`, the spot label shows `* จำเป็นเมื่อพบงานที่ตรงกัน` and `ถัดไป` does not move on: it shows `กรุณาระบุจุดที่ต่างจากงานเดิม ก่อนดำเนินการต่อ` under the spot field and focuses it (the form's normal validation pattern, the button is not greyed out). Typing another spot re-checks #22: a similar-only result lets the user go on; following a case leaves the form as today. The submit-time S04 dialog (409 `DUPLICATE_FOUND`) stays as the fallback for races and skipped checks. Applies to team mode too (BR-F04-3).
3. **S06 for every role (layout):** the list card gets a heading row: `รายการงานซ่อม` + count badge (total for the current tab) on the left, `อัปเดตล่าสุด {time}` on the right; the separate `แสดง {n} งาน` line goes. Tabs, search, status filter, sort, the table columns and the `แสดง {a}–{b} จาก {n} งาน` + page-number footer stay. **No stats row** (owner).
4. **S06 for `housekeeper_lead` / `security_lead`:**
   - The blue CTA card has two buttons: white `แจ้งซ่อมใหม่` (→ `/repair/new`) and an outlined-on-blue `บันทึกงานที่ทีมแก้แล้ว` (→ `/repair/new?mode=team`); sub-line `เรียกช่างช่วยดูแล หรือบันทึกงานที่ทีมแก้ไขแล้ว`. Other roles keep one button and the current sub-line.
   - Four relation tabs: `ทั้งหมด · ที่ฉันแจ้ง · ที่ฉันติดตาม · ทีมแก้เอง` (`?scope=team`). `ทีมแก้เอง` = tickets the lead reported that are still `closed` / `team_handled` (a handed-over ticket leaves this tab and stays under `ที่ฉันแจ้ง`).
   - Rows of team-handled tickets show `· ทีมแก้เอง` after the ticket no (from `closedReason`; all roles).
5. **S03 team mode is locked (behaviour, BR-F04-1):** the `เรียกช่าง | ทีมแก้เองแล้ว` switch is removed. The mode comes from the entry point: `/repair/new` = repair, `/repair/new?mode=team` = team (non-leads get repair). Heading / breadcrumb / submit follow the mode (`บันทึกงานที่ทีมแก้แล้ว` in team mode); the summary shows the mode. A note under the form: `ต้องการเปลี่ยนประเภทงาน? ปิดฟอร์มนี้แล้วเริ่มใหม่ ข้อมูลที่กรอกจะไม่ถูกบันทึก`. Drafts are kept per mode. S05 team variant's "record another" opens `?mode=team`.
