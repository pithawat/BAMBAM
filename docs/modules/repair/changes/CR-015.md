## What changes

ผู้ใช้: "admin ไม่ต้องแก้ priority ตอนคนอื่นสร้าง ticket มาแล้ว priority เป็นแค่นโยบายเฉยๆ ตอนปฏิบัติจริงไม่ต้องเรียงตาม priority"

1. Admin no longer changes a ticket's priority after it is created (F22 "ปรับความเร่งด่วน" removed; endpoint #20 dropped).
2. Priority is still set by the system at report time (BR-F02-2, CR-008) and kept as policy information.
3. Work lists are no longer ordered by priority (S09 technician list, S11).

## Why

Priority is a policy guideline only; in day-to-day work the team does not pick jobs by priority.
