# CR-023 — Contractor shop names must be unique

Status: DONE (2026-10-26) · approved 2026-10-26   <!-- PROPOSED → APPROVED → DONE (or REJECTED) -->
Requested: 2026-10-26 by owner (while reviewing e2e coverage of F21 / F24)
Size: M

## What changes

ตอนช่างสร้างช่างภายนอก (F24) ห้ามสร้างร้านที่ชื่อซ้ำกับร้านที่มีอยู่แล้ว (ไม่สนตัวพิมพ์) — ปัจจุบันสร้างซ้ำได้.
ให้ระบบบอกว่ามีร้านนี้แล้ว และชวนเลือกร้านเดิมแทน. ชื่อประเภทช่างภายนอกคงกฎเดิม BR-F24-2 (ชื่อซ้ำ = ใช้ประเภทเดิม ไม่ error).

## Why

The owner expects one record per shop, so job history and average scores are not split across copies of the
same contractor (BR-F24-5). Today `repair.contractors` has only a non-unique index on `lower(name)`.
