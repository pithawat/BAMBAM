## What changes

โมดูลใหม่ `settings` (D-043–D-047) ทำให้ role เพิ่ม/ลบได้และสิทธิ์ตั้งใน matrix ระบบแจ้งซ่อมจึงต้อง:

- **A. เช็คสิทธิ์แทนชื่อ role** (backend และ FE) โดยค่าตั้งต้นให้ผลเหมือนเดิมทุก role (BR-F29-2); เมนูตาม D-050
- **B. อาคาร / ชั้นเป็นข้อมูลกลาง** ใน `platform` (D-048) — ฟอร์มและงานเดิมใช้ id เดิม; ภาพรวมอาคาร S12 เปิดรูปผังชั้นได้ และยังแสดงชั้นที่ปิดใช้งานจนกว่างานค้างในชั้นนั้นจะปิดครบ (BR-F26-4, BR-F26-5)
- **C. ประเภทผู้รับเหมา:** ช่างพิมพ์ชื่อตรงกับประเภทที่ถูกปิดใช้งาน → ใช้ประเภทเดิมและเปิดใช้งานกลับ; การสร้างประเภทของช่างบันทึกลงประวัติ (F28, F30)

## Why

ผู้ใช้ขอหน้า Superadmin (2026-10-15) และอนุมัติ flow ของ settings (2026-10-16) ถ้า repair ยังเช็คชื่อ role การติ๊กสิทธิ์ใน matrix จะไม่มีผล
