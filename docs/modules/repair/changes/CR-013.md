# CR-013 — Make the repair evaluation entry explicit

Status: PROPOSED
Requested: 2026-10-19 by project owner
Size: S

## What changes

Refine only the reporter's awaiting-rating review card on S07:

- Heading: `ซ่อมเสร็จแล้ว · รอคุณประเมิน`.
- Supporting copy: `ตรวจผลซ่อมด้านล่าง แล้วกดประเมินงานซ่อมเพื่อให้คะแนนและแสดงความคิดเห็น`.
- Replace the small `ประเมินพร้อมความคิดเห็น` text action with a prominent warm-orange Button labeled `ประเมินงานซ่อม`, with a star icon and trailing arrow. Full width on phones, natural width on desktop, minimum 44px touch height. Owner requested less blue after reviewing the initial preview; revision 2 uses the existing attention colour (`#B93D0A`) for this entry.
- Place the primary button before the optional five-star shortcut; label the shortcut `หรือเลือกคะแนนเพื่อเริ่มประเมิน` so its purpose is explicit.
- Add an attention-colour top border, a lighter outline and a subtle warm background to distinguish the review card from informational status cards, using the existing attention token.
- Keep the deadline and `ยังไม่เรียบร้อย · ส่งกลับให้แก้` as secondary information/actions.
- The primary button opens the existing S08 dialog without a selected score. Star shortcuts retain draft-score behavior. Only the existing confirmation in S08 submits the evaluation.

## Why

The owner reports that the evaluation entry looks like an ordinary status strip and is difficult to identify as actionable.
