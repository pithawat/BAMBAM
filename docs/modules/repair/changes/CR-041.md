## What changes

- **S09 phones / tablets (below `lg`):** the one-row segmented tabs (`รับเรื่อง 7` · `กำลังดำเนินการ 4` · `รอประเมินตรวจงาน 3`, no wrap, so labels ran into each other) become **three equal tiles** in a row: count large on top with the step colour dot (`status-new` / `status-in-progress` / `status-resolved`), label under it (may wrap to 2 lines). Selected tile = filled `foreground`, white text. Still one radio group `ขั้นของงาน`, each radio named `{label} {count}`. The อาคาร filter sits under the tiles; the toolbar card is dropped on phones (the tiles are cards themselves).
- **Desktop S09:** unchanged (toolbar card: segmented tabs + อาคาร filter).
- **S09 header:** the `ช่างภายนอก` button right of the title `งานซ่อม` is removed on every size. S18 stays reachable from the repair section nav (`งานซ่อม | ช่างภายนอก`, D-050).

## Why

Thai labels plus counts do not fit three segments at 360–390 px. The header button duplicated the section nav item next to it.
