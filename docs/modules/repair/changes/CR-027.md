### Lightweight approach (proposal)

- Shapes stay as code (procedural three.js, no GLB / texture download); one registry `modelKey → build function`, each building file loaded with dynamic `import()` only when needed.
- Site view = low-detail blocks (one box + roof per building, merged geometry, shared materials, render on demand); the full model + floor plan only when one building is opened. Ticket pins in the site view = one marker per building with its count.
- New column `platform.buildings.model_key` (nullable) + site position (`site_x`, `site_z`, `site_rot`); #27 returns `modelKey` and the site position (additive).
