# Local demo fonts

Anuphan Thai and Latin variable WOFF2 subsets, reused from this repository's existing Next.js font cache (`frontend/.next/static/media`). Bundled here so the design review works without a connection to Google Fonts. These files are only used by the CR-008 HTML prototypes.

Original typeface: Anuphan by Cadson Demak. Source and SIL Open Font License: https://github.com/google/fonts/tree/main/ofl/anuphan
