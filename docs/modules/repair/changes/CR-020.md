## What changes

User's words (2026-10-24): "ถ้าเคสซ้ำกัน หมวด + ชั้น + ห้องเดียวกัน ให้ขึ้นติดตามงานที่มีอยู่แล้ว ไม่สามารถสร้างเคสใหม่ได้ ขอข้อความที่ทำให้ user เข้าใจด้วย" · on a different spot in the same room: "ให้สร้างเคสใหม่ได้ดีกว่า แค่มีขึ้นมาโชว์ว่ามีงานคล้ายกันแล้ว แล้วให้โชว์การ์ดเคสนั้นขึ้นมา เพื่อความยืดหยุ่น และ admin ปิดเคสได้ทันทีอยู่แล้ว"

1. **Duplicate vs similar (BR-F03-1/2):** an open ticket in the same category + floor + room is a **duplicate** when the reporter gives **no extra spot** (`บอกจุดเพิ่มเติม`) or the **same** spot (trimmed, spaces collapsed, any case) → follow the old case or cancel; a new ticket cannot be created. With **another** extra spot it is only **similar** → S03 shows the case card (`มีงานคล้ายกันในห้องนี้`) and the report can be sent. Old tickets without a room have no own spot: only an empty spot is a duplicate of them.
2. **Clear copy** for the duplicate / similar cards and the S04 dialog (below).
3. Own ticket awaiting ประเมินตรวจงาน → button **`ไปประเมินตรวจงาน`** (S04; S03's `ไปที่งานของคุณ` dropped).
4. **`ยกเลิกการแจ้ง`** → discard confirm (`_common.md` §7) → back to where the form was opened (Home without history).
5. After **follow** → toast + the normal S07 detail page; the follower sees progress but cannot rate (BR-F03-3). No S05 follow variant.
6. Hand-over dialog body: **`งานเดิม เลขเดิม จะส่งกลับไปที่ช่าง รอช่างกำหนดวันเสร็จ`** (no queue / priority order since CR-005 / CR-015).
7. **D-098 confirmed:** reporters who meet a duplicate / similar card see the report photos of that open case (helps tell the spot apart).
