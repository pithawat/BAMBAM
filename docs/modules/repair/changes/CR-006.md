# CR-006 — ตัดสินใจ "ช่างในระบบ / ช่างภายนอก" ตั้งแต่ตอนประเมิน

Status: APPROVED (2026-10-15) — applied inside Stage 2, waiting for stage acceptance
Requested: 2026-10-15 by ผู้ใช้ (owner)
Size: M (contract + screens of Stage 2, no new table; amends CR-005 / D-039)

## What changes

ผู้ใช้: ช่างประเมินตั้งแต่แรกว่าจะทำเองหรือให้ช่างนอกระบบทำ และมีฟอร์มกรอกข้อมูลช่างนอกตั้งแต่กดประเมิน; ตอนบันทึกผลจึงไม่ต้องเลือกอีก

1. **ประเมินงาน (S17)** = วันที่คาดว่าจะเสร็จ + **ผู้ดำเนินการ** (ช่างในระบบ / ช่างภายนอก); ถ้าช่างภายนอก เลือกจากรายชื่อหรือ "เพิ่มใหม่" (ฟอร์ม S18 เดิม) ในกล่องเดียวกัน
2. **บันทึกผลซ่อม (S10)** = สิ่งที่ทำ + รูป; ไม่มีตัวเลือกผู้ดำเนินการ; ถ้าเป็นงานช่างภายนอก ให้**คะแนนช่างภายนอก 1–5** (บังคับถ้ายังไม่มีคะแนน — ให้ก่อนงานเสร็จไม่ได้)
3. **แก้การประเมินได้** (เช่น ช่างนอกไม่มา เปลี่ยนเป็นทำเองหรือเปลี่ยนเจ้า) ระหว่าง `in_progress`; ทุกครั้งเป็น event `assessment_changed`; เปลี่ยนช่างนอก → คะแนนของเจ้าเดิมถูกล้าง
4. ผู้แจ้งเห็น "ดำเนินการโดยช่างภายนอก · {ประเภท}" ตั้งแต่ขั้นกำลังซ่อม

## Why

งานจริง: ช่างตัดสินใจเรื่องนี้ตอนดูงาน และวันคาดเสร็จขึ้นกับตัวเลือกนั้น; Admin เห็นว่าช่างนอกเจ้าไหนกำลังทำงานอะไร; ประวัติงานของช่างนอกครบแม้งานยังไม่เสร็จ
