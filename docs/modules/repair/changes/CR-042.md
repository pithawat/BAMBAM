- **S09 งานซ่อม:** "โหลดเพิ่ม" (20 at a time, appended) → **numbered pages of 5**. The FE sends the step tab, อาคาร and `page` / `pageSize=5` to #6 `GET /tickets`; the API filters, sorts (oldest first) and pages in SQL (`LIMIT` / `OFFSET` + count) and returns `meta.total`. Page in the URL (`?page=`); a new tab or building → page 1; page change scrolls to the top.
- **S18 ช่างภายนอก:** one call with `pageSize=100` (all on one page) → **numbered pages of 5** from #15 `GET /contractors` (`q`, `includeInactive`, `page`, `pageSize=5`), same SQL paging. Search, แสดงที่ปิดใช้งาน and the page live in the URL (`?q=&inactive=1&page=`), so one change sends one request; a new search / toggle → page 1.
- Footer under each list: `แสดง {from}–{to} จาก {total} งาน` (S09) / `… ร้าน` (S18) + the S06 pager (‹ 1 … n ›). An empty page past the end shows `ไม่มีงานในหน้านี้` / `ไม่มีรายการในหน้านี้` + `กลับหน้าแรก`.
