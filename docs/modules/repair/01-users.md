## Persona: พนักงานทั่วไป (`employee`)

- **Who:** พนักงาน CPAC สำนักงานใหญ่ทุกคนที่ login ผ่าน RMC SSO ได้ ✏️ ช่วงอายุ / ความคุ้นเคยกับแอป
- **Where and on what:** **มือถือเป็นหลัก** ตอนเจอปัญหาหน้างาน (ยืนอยู่หน้าจุดที่เสีย ถ่ายรูป / สแกน QR ที่อุปกรณ์) · desktop ได้ แต่ไม่ใช่หลัก
- **How often:** ✏️ (นานๆ ครั้ง — ต้องใช้ได้โดยไม่ต้องเรียนรู้)
- **Jobs to be done:** แจ้งปัญหาให้ถึงช่าง · รู้ว่าช่างจะเสร็จเมื่อไร · ประเมินงาน (ให้ดาว) เมื่อซ่อมเสร็จ (CR-005)
- **A day with this task:** เดินไปห้องประชุม แอร์ไม่เย็น → เปิด BAMBAM บนมือถือ กด "แจ้งซ่อม" (หรือสแกน QR ที่แอร์) → เลือกหมวด/อาการ ถ่ายรูป เลือกความเร่งด่วน → ส่ง → ระบบบอกว่ามีคนแจ้งเรื่องเดียวกันแล้ว เลือกติดตามเคสนั้นแทน → กระดิ่งแจ้งว่าช่างประเมินแล้ว คาดว่าเสร็จพรุ่งนี้ → ภายหลังแจ้งว่าซ่อมเสร็จ → เปิดดูรูปหลังซ่อม กดประเมินงาน ให้ 5 ดาว (CR-005)
- **Frustrations today:** (จาก POC) งานไม่ถึงคนอื่นเพราะเก็บในเบราว์เซอร์ · เห็นงานของทุกคนปนกัน · กระดิ่งเหมือนกันทุกคน
- **Success looks like:** ✏️ (เสนอ: แจ้งเสร็จภายใน 1 นาทีบนมือถือ)
- **Words they use:** แจ้งซ่อม, ติดตามงาน, ตรวจรับ / ประเมินงาน, ด่วน/ฉุกเฉิน

## Persona: หัวหน้าแม่บ้าน / หัวหน้ารปภ. (`housekeeper_lead`, `security_lead`)

- **Who:** หัวหน้าทีมที่ดูแลพื้นที่ ทีมแก้ปัญหาเล็กๆ ได้เอง
- **Where and on what:** **มือถือเป็นหลัก** เดินตรวจพื้นที่
- **How often:** ✏️ (บ่อยกว่าพนักงานทั่วไป)
- **Jobs to be done:** ทุกอย่างของพนักงาน + บันทึกงานที่ทีมแก้เองให้นับเป็นผลงาน (F04) + ส่งต่อให้ช่างถ้าทีมแก้ไม่จบ (F05)
- **A day with this task:** ✏️ (ขอเรื่องจริง 1 เรื่อง)
- **Success looks like:** บันทึกงานที่ทีมทำเองได้ในไม่กี่ขั้น และส่งต่อช่างได้โดยไม่ต้องแจ้งใหม่

## Persona: ช่างเทคนิค (`technician`)

- **Who:** ช่างในระบบ มีคนเดียว ดูแลทุกหมวด (CR-005) งานที่เกินกำลังจ้างช่างภายนอก
- **Where and on what:** **มือถือเป็นหลัก** อยู่หน้างาน มือไม่ว่าง ถ่ายรูปหลังซ่อม
- **How often:** ทั้งวัน
- **Jobs to be done:** เห็นทุกงานที่ยังไม่ปิด เรียงตามความเร่งด่วน · ประเมินงาน (วันคาดว่าเสร็จ + ผู้ดำเนินการ: ทำเอง / ช่างภายนอก) · บันทึกผล + รูปหลังซ่อม + คะแนนช่างภายนอก · ดูแลข้อมูลช่างภายนอก · กรองตามอาคารได้ (CR-001, CR-005, CR-006)
- **A day with this task:** เปิด "งานซ่อม" แท็บรอประเมิน งานบนสุดคือ "ฉุกเฉิน" → ประเมินงาน: เสร็จวันนี้ ช่างในระบบทำเอง → ไปหน้างาน ซ่อม ถ่ายรูป → บันทึกผล → งานเป็น "ซ่อมเสร็จ รอประเมิน" → งานแอร์ใหญ่ประเมินเป็นช่างภายนอก → ร้านมาซ่อม → บันทึกผล + ให้คะแนนร้าน → ถ้าผู้แจ้งส่งกลับ งานกลับมาในขั้น "แก้ไขตามที่ส่งกลับ" (CR-005, CR-006)
- **Success looks like:** ✏️ (เสนอ: รู้ว่างานถัดไปคืออะไรโดยไม่ต้องถามใคร)

## Persona: Admin (`admin`)

- **Who:** ผู้ดูแลงานอาคาร / ศูนย์จัดการงาน
- **Where and on what:** **desktop เป็นหลัก** ที่โต๊ะทำงาน
- **How often:** ทั้งวัน
- **Jobs to be done:** เห็นทุกงาน · ปรับความเร่งด่วน · ปิด Ticket ใดก็ได้ · ส่งต่องานทีมให้ช่าง · ดูช่างภายนอก คะแนน และประวัติงาน · ดูภาพรวมทั้งอาคารแบบ 3D ว่าจุดไหนมีปัญหา (CR-005: ไม่มีเลื่อนลำดับคิว)
- **Success looks like:** ✏️

## Persona: ผู้บริหาร (`executive`)

- **Where and on what:** desktop เป็นหลัก
- **Jobs to be done:** ช่วงแรกเห็นทุกอย่างเหมือน Admin (ทุกงาน, ช่างภายนอก, ภาพรวมอาคาร 3D) แต่**อ่านอย่างเดียว** — ปิดเคส ปรับความเร่งด่วน ส่งต่อ ไม่ได้ (approval 2026-10-14, CR-005). Insights (F11) มาทีหลัง

## Anti-persona

- ผู้รับเหมาภายนอก / คนที่ไม่มีบัญชี RMC SSO — ไม่ได้ออกแบบให้ใช้
- ไม่ออกแบบหน้าจอ desktop ของช่างและพนักงานให้ละเอียดเท่ามือถือ (ใช้ได้ แต่ไม่ใช่หลัก) และกลับกันสำหรับ Admin
