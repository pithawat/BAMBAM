# Master หมวดงานและอาการที่พบ

ข้อมูลสำหรับช่อง “เกิดอะไรขึ้น” และ “อาการที่พบ” ในฟอร์มแจ้งซ่อม / ขอรับบริการ

แหล่งข้อมูล: `frontend/app/page.tsx` ตัวแปร `categoryGroups`

## 1. ไฟฟ้าและแสงสว่าง

- ไฟไม่ติด/ไฟกะพริบ
- ปลั๊กไม่มีไฟ/สวิตช์เสีย
- ไฟตกหรือดับ
- มีกลิ่นไหม้/ประกายไฟ
- อื่นๆ

## 2. ระบบปรับอากาศ

- แอร์ไม่เย็น
- น้ำหยด/รั่วซึม
- มีเสียงดัง
- มีกลิ่น
- เปิดไม่ติด
- รีโมทเสีย
- อื่นๆ

## 3. ประปาและสุขาภิบาล

- น้ำไม่ไหล
- น้ำรั่วซึม
- ท่อตัน
- ก๊อก/วาล์วเสีย
- ชักโครกเสีย
- ที่กดน้ำยาเช็ดฝาชักโครก/กล่องทิชชู่ชำรุด
- อื่นๆ

## 4. ห้องประชุมและโสตทัศนูปกรณ์

- ไมค์ไม่มีเสียง/เสียงขาด
- ลำโพงไม่ดัง
- จอไม่แสดงผล/ไม่ติด
- กล้องไม่ทำงาน
- สายสัญญาณ HDMI เสีย
- อื่นๆ

## 5. อาคารและพื้นที่ส่วนกลาง

- ฝ้า/ผนังชำรุด
- พื้นแตก/ร่อน
- ประตู/กระจกเสีย
- หลังคารั่ว
- สีลอก
- เสี่ยงหล่นใส่คน
- อื่นๆ

## 6. ลานจอด / ไม้กั้น

- ไม้กั้นค้าง/ไม่ยกลง
- ไม้กั้นไม่ทำงาน
- ไม้กั้นหัก/ชำรุด
- ที่จอดรถชำรุด/พื้นแตก
- เส้นจราจรลบเลือน
- ป้าย/สัญญาณจราจรเสีย
- ไฟส่องสว่างลานจอดดับ
- อื่นๆ

## 7. อื่น ๆ

- ใช้งานไม่ได้
- มีเสียง/กลิ่นผิดปกติ
- รั่วซึมชำรุด
- มีความเสี่ยงอันตราย
- อื่นๆ โปรดระบุ

## เงื่อนไขการเลือก

- เลือกหมวดงานได้ครั้งละ 1 หมวด
- เลือกอาการได้หลายรายการ โดยต้องเลือกอย่างน้อย 1 รายการ
- เมื่อเปลี่ยนหมวดงาน ระบบจะล้างอาการที่เลือกไว้เดิมและข้อความระบุอาการอื่นๆ
- รายการ Master ปัจจุบันกำหนดไว้ในโค้ดหน้าเว็บโดยตรง
