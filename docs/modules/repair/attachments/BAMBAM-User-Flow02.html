User Flow ทุกฟีเจอร์

ผู้ใช้แต่ละ role กดอะไร แล้วระบบหรือคนถัดไปทำอะไรต่อจนจบ flow แผนภาพแบ่งคอลัมน์ตามผู้ทำขั้นตอน (swimlane) และมาร์กจุดที่โค้ดยังไม่ตรงกับเจตนาไว้บนกล่อง

อ้างอิงโค้ดเดิมและข้อกำหนดปรับปรุงปรับตามข้อกำหนดวันที่ 13 ต.ค. 2569: Login ผ่าน SSO รับ username / role, Admin ปิดได้ทุก Ticket และ F05 ส่งกลับคิวเดิมเท่านั้น ส่วนที่ปรับเป็น flow ที่ต้องการ ยังไม่ได้ยืนยันการพัฒนาในแอปจริง · สรุปจากรายงานสำรวจ Feature / Role / Permission วันที่ 9 ต.ค. 2569 ซึ่งอ่านจาก working tree ของ bambam-ai-app ส่วนอื่นอ้างอิงพฤติกรรมตามโค้ดและคู่มือ ไม่ใช่ผลทดสอบเว็บ Production
BAMBAM ยังเป็น POCงานซ่อม คำขอจัดห้อง และข้อมูลที่แก้ อยู่ในเบราว์เซอร์ที่ใช้งาน ยังไม่มี backend กลาง ขั้นตอนที่ส่งต่อระหว่าง role จึงยังไม่ถึงผู้ใช้ที่เปิดจากเครื่องอื่น
