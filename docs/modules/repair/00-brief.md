# ระบบแจ้งซ่อม — Brief

<!-- Drafted by Claude from the kickoff on 2026-10-14 and the attached flow file. Edit freely. -->

## Goal

พนักงาน CPAC สำนักงานใหญ่แจ้งปัญหาในที่ทำงานได้เร็วจากมือถือ ช่างเห็นงานในหมวดของตัวเองเรียงตามความเร่งด่วน
ผู้แจ้งติดตามและตรวจรับงานได้เอง Admin เห็นภาพรวมทั้งอาคารและจัดลำดับงานได้
วัดผลจาก: ✏️ (เช่น เวลาจากแจ้งถึงช่างรับงาน, % งานที่ผู้แจ้งตรวจรับ)

## Problem today

BAMBAM เดิมเป็น POC: งานซ่อม คำขอ และข้อมูลที่แก้อยู่ใน state ของเบราว์เซอร์ ไม่มี backend กลาง
งานที่ส่งต่อระหว่าง role ไม่ถึงผู้ใช้เครื่องอื่น และการกันสิทธิ์อยู่ฝั่งเบราว์เซอร์อย่างเดียว (จากไฟล์ flow แนบ)

## Users (rough)

| Role | ทำอะไร | อุปกรณ์หลัก |
|---|---|---|
| พนักงานทั่วไป | แจ้งซ่อม ติดตาม ตรวจรับ ให้คะแนน | มือถือ |
| หัวหน้าแม่บ้าน / หัวหน้ารปภ. | + บันทึกงานที่ทีมทำเอง, ส่งต่อให้ช่าง | มือถือ |
| ช่างเทคนิค | ดูคิวในหมวดของตัวเอง กดรับงาน บันทึกผลซ่อม | มือถือ |
| Admin | เห็นทุกงาน จัดลำดับคิว ปรับความเร่งด่วน ปิดงาน ภาพรวมอาคาร 3D | desktop |
| ผู้บริหาร | ดูภาพรวม / Insights (ช่วงหลัง) | desktop |

Role ใช้ชุดเดียวทั้ง 3 ระบบ, 1 role ต่อคน, เก็บใน BAMBAM (D-003, D-004)

## Features (must have) — Phase 1 (D-009)

- F01 เข้าสู่ระบบผ่าน RMC SSO, โปรไฟล์จาก claim ของ SSO, role จาก BAMBAM + ตัวสลับบทบาท dev/UAT (D-005)
- F02 แจ้งซ่อม: หมวด อาการ อาคาร/ชั้น รายละเอียด รูป **ความเร่งด่วนที่ผู้แจ้งเลือก** (D-007)
- F03 ตรวจงานซ้ำ → ติดตามเคสเดิม
- F04 หัวหน้าทีมบันทึกงานที่ทีมทำเอง → ปิดทันที
- F05 ส่ง ticket เดิมกลับเข้าคิวช่าง
- F06 ติดตามงานและประวัติ
- F07 ผู้แจ้งตรวจรับและให้คะแนน
- ใหม่: คิวงานช่าง — เห็นเฉพาะหมวดของตัวเอง กด "รับงาน" → บันทึกผลซ่อม + รูปหลังซ่อม → resolved (D-006)
- ใหม่: Admin เลื่อนลำดับคิวได้ (ลำดับที่ Admin ตั้งชนะลำดับอัตโนมัติ, บันทึกว่าใครเลื่อน) และปรับความเร่งด่วน
- ใหม่ (mockup ก่อน): หน้าภาพรวม Admin เป็นอาคาร 3D มีหมุดจุดที่มีปัญหา (D-010)

## Nice to have (later)

- F08 ส่วนที่เหลือของศูนย์จัดการงาน, F09 SLA, F10 ค่าใช้จ่าย, F11 Insights, F12 คลังอุปกรณ์, F13 ป้าย QR, F14 ผังอาคาร, F15 จัดการผู้ใช้/role, F16 แชท, F19 ภาษา/ธีม/แจ้งเตือน
- F17 คำขอจัดห้อง และ F18 ลิงก์บริการภายนอก — ต้องตัดสินว่าย้ายไป `room_booking` / `car_booking` หรือไม่

## Out of scope

- การมอบหมายงานโดย Admin ในช่วงแรก (D-006)
