  • เลือก 1 แบบ หรือผสม เช่น "หัวของ A + ความแน่นของ B บน desktop" หรือ "สีของ C + ฟอนต์ของ A"
  • ลองย่อหน้าต่างเบราว์เซอร์ดูกรอบมือถือ และเลื่อนในกรอบได้
